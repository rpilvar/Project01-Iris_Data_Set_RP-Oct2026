# Iris Flower Classification Project

## 1. Project Overview

This project uses machine learning to classify Iris flowers into three species based on measurements of their flower parts.

The project is developed using Python and the Scikit-learn machine learning library. It is intended to demonstrate the basic workflow of a supervised machine learning classification problem.

## 2. Project Objectives

The objectives of this project are to:

- Load and explore a dataset using Python.
- Understand the features and target labels in a dataset.
- Split the dataset into training and testing sets.
- Train a machine learning classification model.
- Generate predictions using the trained model.
- Evaluate the model using accuracy and a confusion matrix.

## 3. Dataset

The project uses the Iris dataset available through Scikit-learn.

The dataset contains 150 flower samples belonging to three species:

- Setosa
- Versicolor
- Virginica

Each sample has four numerical features:

- Sepal length
- Sepal width
- Petal length
- Petal width

The target variable represents the Iris species.
